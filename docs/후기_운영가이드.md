# 한국어 수업 후기 운영

후기는 수강생에게 개별적으로 전달한 Google Forms에서 수집합니다. 사이트에는 공개 글쓰기 기능이 없습니다. 후기 페이지(`/reviews`)는 누구나 읽을 수 있지만, 생성·수정·삭제는 GitHub 권한이 필요한 Keystatic 관리 화면에서만 합니다.

1. Google Forms 응답에서 실제 수강 여부와 **사이트 공개 동의**를 확인합니다. 비공개 개선 의견은 게시하지 않습니다. 현재 저장소는 공개 저장소이므로 동의 전 후기나 비공개 답변을 CMS에 저장하지 않습니다.
2. `/keystatic`의 **Korean class reviews · 수업 후기**에서 항목을 만듭니다. 내부 ID에는 실명·연락처를 쓰지 않습니다. 과정, 수강생이 허락한 공개 이름(없으면 빈칸), 후기 문장만 입력합니다. 번역을 하지 않았다면 원문 언어만 채워도 됩니다.
3. 공개 준비가 끝나면 **Publication consent checked**를 켜고 **Hide from website**를 끕니다. 둘 중 하나라도 만족하지 않으면 사이트에 나오지 않습니다. 이 숨김 설정은 GitHub 저장소의 비공개 설정이 아닙니다. 수정·삭제도 같은 관리 화면에서 합니다.
4. 운영 사이트에서 저장한 후기 변경은 GitHub에 검토용 PR로 올라갑니다. 블로그와 달리 자동 병합되지 않습니다. 폼 응답과 게시 문장을 대조하고 본인이 PR을 병합하면 재배포 후 반영됩니다. 로컬 관리 화면에서는 로컬 파일이 변경되므로 직접 커밋·배포해야 합니다.

**권한:** Keystatic의 운영 로그인은 GitHub 저장소 쓰기 권한을 따릅니다. 본인만 관리하려면 저장소 Write 권한과 Keystatic GitHub App 접근을 본인 계정으로 제한해야 합니다. 브라우저에서 관리자 화면 주소를 감추는 것만으로는 권한 제한이 되지 않습니다.
