# MyanMate 한국어 수업 오픈 준비

## 사이트의 역할

수강생이 수업을 이해하고 상담을 신청하는 사이트입니다. 신청은 수강 확정이나 결제가 아닙니다. 가격과 일정은 개별 상담에서 안내합니다. 학생 로그인은 없습니다.

핵심 흐름: **홈에서 수업 선택 → 수업 상세 확인 → 신청 → 24시간 이내 연락 → 상담 후 수강 확정**.

## 현재 안내 기준

| 과정 | 기간 | 신청 |
| --- | --- | --- |
| 한글 입문·기초 한국어 | 약 8주 | 가능 |
| TOPIK I 1~2급 대비 | 최대 8주 | 가능 |
| TOPIK II 3~6급 대비 | 최대 8주 | 가능 |
| 말하기: Moe 선생님, 미얀마어 설명 | 약 4주 | 가능 |
| 말하기: Jun Ho 선생님, 상급 회화 | 약 4주 | 가능 |

모든 수업 방식은 온라인입니다. 정원과 1:1 여부는 사이트에서 고정해 안내하지 않습니다. 교재·학습자료·숙제, 주당 횟수와 회당 시간은 아직 미정이므로 확정된 것처럼 안내하지 않습니다.

## 운영자가 정할 다음 일

1. **수업 운영표:** 각 과정의 주당 횟수, 회당 시간, 교재·자료와 숙제 방식을 정합니다. 가격은 상담용으로만 준비합니다.
2. **상담 답변:** 신청서 확인 후 24시간 안에 전화·이메일로 답하고, 현재 수준·목표·시간을 확인하는 공통 답변을 준비합니다.
3. **미얀마어 확인:** Moe 선생님이 홈, 수업 상세, 신청서, 신청 결과와 개인정보 문구를 검토합니다. 앱 문구는 `src/i18n/ui.ts`에서 수정합니다.
4. **공개 전 확인:** 실제 휴대폰에서 수업별 신청을 확인하고 변경된 신청서가 Gmail에 도착하는지 한 번 확인합니다. 현재 작업은 로컬 반영입니다. 공개 배포는 별도로 진행합니다.

## 후기

실제 수강생에게 Google Forms 후기 양식을 개별 전달합니다. 공개 동의가 있는 후기만 관리자 화면에서 게시합니다. 후기가 없을 때는 공개된 후기가 없다고 안내합니다. 자세한 과정은 [후기 운영가이드](./후기_운영가이드.md)를 따릅니다.
