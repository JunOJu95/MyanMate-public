# 미얀마어 문구 검수

## 어디서 수정하나요?

`/keystatic` 왼쪽의 **미얀마어 문구 검수**에서 화면을 선택합니다. 홈, 과정 소개, 말하기, 강사, 수강 안내, FAQ, 신청서, 공통 메뉴, 개인정보, 블로그 화면, 후기 화면, 문의, 소개, 정보·가이드, 기존 서비스, 이전 화면 문구로 나누어져 있습니다.

- 현재 공개 화면의 문구부터 검수합니다. **이전 화면 문구 · 보관용**은 과거 화면을 위한 문구이며 우선순위가 낮습니다.
- 블로그 글의 제목·요약·본문은 **Blog · 블로그**, 정보 글 본문은 **Guide Articles** 또는 **Guide Information**, 실제 후기 본문은 **Korean class reviews**에서 기존처럼 수정합니다. 검수 메뉴의 ‘블로그 화면’과 ‘후기 화면’은 그 화면의 버튼·안내 문구를 관리합니다.
- `127.0.0.1` 주소는 개발 서버가 실행되는 현재 컴퓨터에서만 열립니다. 다른 컴퓨터에서는 운영 관리자 주소와 기존 GitHub 편집 권한을 사용합니다.

## 검수 순서

1. 개인정보·동의·면책과 수강 조건의 의미를 먼저 확인합니다. 수강료 공개 여부, 온라인 수업, 기간, 상담 절차, 강사 자격을 임의로 바꾸지 않습니다.
2. 각 문구의 **한국어 원문**을 읽고 영어를 보조 참고로 사용합니다. 원문은 이 메뉴에서 편집할 수 없습니다.
3. **미얀마어 · မြန်မာ** 칸을 자연스러운 표현으로 수정합니다. 메뉴·버튼은 짧고 명확하게, 설명은 실제 독자가 이해하기 쉽게 씁니다.
4. 원문과 의미가 같은지 확인한 실제 검수자가 **검수 완료 · Reviewed**를 표시합니다. 이 표시는 작업 진행용이며, 표시 여부와 관계없이 저장한 문구가 미리보기/배포에 사용됩니다. 이후 문구나 원문을 바꾸면 재검수하고 표시를 갱신합니다.
5. **Save**로 저장한 뒤 **Preview**에서 미얀마어를 선택합니다. 휴대전화 폭에서 줄바꿈·버튼·신청서·오류 안내를 확인하고 한국어·영어 전환도 확인합니다. 운영 Preview는 현재 공개본이며, PR 병합과 배포 완료 전에는 수정본이 보이지 않을 수 있습니다.

미얀마어 칸은 비워둘 수 없습니다. ‘learn.title’처럼 작은 회색 글씨로 표시된 문구 ID는 수정할 대상이 아니라 문구 위치를 확인할 때 쓰는 고정 ID입니다.

## 저장과 사이트 반영

- **로컬 관리자**: `src/content/ui-copy/{그룹}.json`에 저장됩니다. 로컬 사이트를 새로고침하면 변경한 문구가 보입니다. GitHub나 운영 사이트는 자동으로 바뀌지 않습니다.
- **운영 관리자**: 기존 GitHub 로그인을 사용합니다. `keystatic/*` 브랜치에 저장한 문구는 자동 검사 후 **검토용 PR**로 올라갑니다. 번역 변경은 자동 병합하지 않습니다. 원문 의미와 모바일 표시를 검토하고 PR을 병합하면 기존 배포 연결을 통해 공개 사이트에 반영됩니다.
- 블로그의 기존 발행과 후기의 별도 검토 방식은 유지됩니다. 번역과 후기 또는 블로그를 같이 바꾼 PR은 번역 검토를 마친 뒤 수동으로 병합합니다.

## 개발자가 문구를 추가하거나 원문을 바꿀 때

- 기존 `t()`와 `data-i18n` 키를 유지합니다. 한국어·영어 원문은 `src/i18n/reference.json`, 미얀마어는 `src/content/ui-copy/*.json`에 각각 한 번만 저장합니다.
- 새 키를 `reference.json`에 추가하고 `copy-groups.mjs`의 그룹 분류와 해당 JSON 문구를 함께 추가합니다. 새 문구는 `reviewed: false`로 시작합니다.
- 원문을 변경하면 해당 미얀마어를 다시 검수하고 `reviewed: false`로 갱신합니다. 검수 상태는 의미의 정확성을 자동 판정하지 않습니다.
- `npm run i18n:check`와 `npm run build`를 실행합니다. 누락·빈 값·잘못된 키·그룹 중복은 검사를 통과하지 못합니다.
- `ui.ts`는 동일한 사전을 서버와 브라우저에서 사용하며, 문구가 바뀌면 이전 브라우저 캐시의 번역을 다시 적용하지 않습니다.
